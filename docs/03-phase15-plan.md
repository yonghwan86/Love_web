작성 2026-08-12 · 상태: **계획만. 착수는 발표(8/14) 뒤** · 근거: 2026-08-09~12 대화

## 0. 한 줄 요약

키링 태그는 그대로 두고, **놀이가 뜨는 무대를 "근처의 가장 큰 화면"으로 옮긴다.** 푸시로 밀어 띄우는 게 아니라, 페어링된 큰 화면이 대기하다가 태그 순간 깨어난다. 제품 이름은 **놀이열쇠**를 추천 (미확정 — 상표 확인 전).

---

## 1. 멀티스크린 무대

### 1.1 출발 아이디어 (사용자 제안)

키링을 부모 폰에 태그 → 푸시로, 사전에 설치·연결된 패드·PC·스마트 TV에 놀이를 띄운다 → 근처에 큰 화면이 없으면 부모 폰에 띄운다(폴백).

### 1.2 플랫폼 사실 — "푸시로 띄우기"가 그대로는 안 되는 이유 (2026-08 검증)

- 웹 푸시는 **알림 배너까지만** 간다. 앱을 사람 손 없이 전면 실행하는 것은 iOS·Android·Windows 전부에서 막혀 있다. 네이티브 앱도 전화·알람류 특수 권한만 예외이고, 웹/PWA에는 그 권한 자체가 없다.
- iOS·iPadOS는 **홈 화면에 설치한 PWA만** 푸시를 받는다 (16.4+). 브라우저 탭은 못 받는다.
- 스마트 TV 브라우저에는 웹 푸시도 PWA 설치도 없다. TV를 잡는 방법은 캐스트(크롬캐스트·에어플레이) 또는 TV 브라우저에 페이지를 열어두는 것뿐.
- NFC 태그는 **태그한 그 폰에서만** URL을 연다. 태그가 다른 기기로 신호를 직접 보낼 수 없다 — 폰이 항상 중계자다.

### 1.3 확정 설계 — 3단 사다리: "밀지 말고, 기다리게"

카훗·잭박스·토니박스가 같은 문제를 푸는 구조.

| 상황 | 동작 | 탭 수 |
| --- | --- | --- |
| 큰 화면이 대기 중 (정원 액자 모드) | 실시간 채널로 즉시 무대 전환 | **0탭** |
| 대기 화면은 없지만 PWA 설치됨 | 푸시 배너 "놀이를 시작했어요 → 무대 열기" | 1탭 |
| 둘 다 없음 | 폰에서 현행대로 | 폴백 |

- **동작 원리 (0탭 단)**: 큰 화면은 "닫혀 있다가 열리는" 게 아니라 **이미 열려 있는 페이지가 화면을 바꾸는 것**이다. 대기 중인 패드의 가온이 페이지는 서버와 실시간 연결(WebSocket)을 유지한 채 가족 채널을 듣고 있고, 태그된 폰이 그 채널로 "무궁화꽃 시작" 신호를 보내면 패드 페이지가 즉시 정원→놀이로 전환한다. 카톡 창이 열려 있으면 새 메시지가 알림 없이 즉시 올라오는 것과 같은 방식. 페이지가 닫혀 있으면 이 단은 성립하지 않는다 → 다음 단(PWA 푸시 1탭 / 폰 폴백).
- **페어링**: 익명 가족 코드 6자리, 1회. 로그인·이메일 없음 (불변 원칙 유지).
- **정원 액자 모드**: 패드·TV 브라우저에 정원을 전체화면 상시 표시(Screen Wake Lock). 토니박스의 "전용 기기가 항상 기다린다"의 웹 구현.
- 태그 직후 폰이 묻는다: **"어디서 놀까? 🛋️ 거실 화면(추천) / 📱 이 폰"** — 큰 화면이 대기 중일 때만 묻고, 아니면 질문 없이 폰에서 시작.

### 1.4 역할 분담 — 폰 = 비밀·입력·카메라, 큰 화면 = 가온이의 무대

| 놀이 | 큰 화면 (무대) | 폰 (리모컨) |
| --- | --- | --- |
| 무궁화꽃 | 사회·구호·판정 발표 | 심판 카메라 — 판정은 지금처럼 기기 안에서만, 영상 전송 없음 |
| 몸으로 말해요 | 타이머·정답 축하 | **비밀 단어** (큰 화면에 뜨면 스포일러) |
| 끝말잇기 | 말 사슬을 크게 | 입력 (타이핑·음성) |
| 역할놀이 | **제외** — 이어폰 속삭임이 본질이라 큰 화면 이득 없음 | (현행 유지) |
| 물 주기·정원 | 정원을 가득 — 이 기능의 백미 | 물 주기 버튼 |

### 1.5 지금도 되는 것 (코드 0줄)

같은 URL을 패드·노트북에서 열면 그대로 큰 화면 놀이가 된다 (반응형이고 패드는 카메라도 있다). 발표 시연에서 "거실의 가온이" 그림을 보여줄 최단 경로.

### 1.6 가드레일 — 불변 원칙과의 접점

- 이 기능이 **서버 최초 도입 지점**이다. 채널에는 게임 상태 신호만 싣는다. 영상·사진·음성은 절대 전송하지 않는다 (판정은 폰 온디바이스 유지).
- 로그인 대신 익명 가족 코드 — PII 없음.
- 보호자 동의 설계와 같은 배치로 진행한다 (발표 후 범위와 일치).

### 1.7 기술 후보

- 실시간 채널: **Supabase Realtime** (계정 보유) + 가족 코드 = 채널명
- PWA: manifest + 서비스워커 + 푸시 구독 저장
- TV: 자동화 포기, 수동 캐스트 안내 + TV 브라우저 대기 모드

### 1.8 2차(02 문서)와의 구분

1.5는 **같은 5~9세** 대상이고 폰이 리모컨으로 남는다. 2차는 10~18세이고 폰을 엎는다. 별개 단계 — 합치지 않는다.

## 2. 제품 이름 (미확정 — 추천안)

### 2.1 기준 다섯

1. **글 못 읽는 5살의 입에 붙어야** 한다 — 이름은 화면이 아니라 말 속에 산다. "○○ 하자!"에 들어가는지가 1차 시험.
2. 특정 부모·성별 프레임 금지 (불변 원칙).
3. AI를 간판에 걸지 않는다 — 제품 철학이 "가온이는 물러나고 가족이 논다"인데 이름이 AI를 앞세우면 모순.
4. 실물 앵커와 정직하게 일치 — 토니박스가 강한 건 이름이 곧 파는 물건이라서.
5. 2차(10~18세)까지 생존 — 유아틱한 이름은 사춘기에서 죽는다.

### 2.2 추천: **놀이열쇠** — 캐릭터는 가온이 유지

토니박스(제품)/토니(캐릭터) 구조. 캐릭터 이름은 2026-08-10에 **'가온이'(가족의 온기)**로 확정 — 옛 이름 '사랑이'는 일반명사 '사랑'과 겹쳐 제품명으로 쓰면 검색·스토어·상표에서 묻히는 문제가 있었다. '가온'은 그 충돌이 없어서, 제품명·캐릭터명 통합안('가온이' 단일 브랜드)도 발표 후 재검토 후보가 된다.

- 소환 장면이 이름 안에 있다: "아빠! 내 놀이열쇠 가져올게!" — 아이가 자기 키링을 부르는 이름이 곧 제품명.
- 역전의 상징: 열쇠는 원래 어른의 물건인데, 이 집 놀이 시간의 열쇠는 아이 주머니에 있다. 피치 라인: **"우리 집 놀이의 열쇠는 아이 주머니에 있습니다."**
- 열쇠는 유아 조기 습득 단어라 발음 문제없고, 유아틱하지 않아 2차의 "입장(QR로 문 열기)" 은유까지 일반화된다.
- 키링 자체가 상품이 되는 사업 구조(토니 피규어 경제학)와 이름이 일치: 파는 물건 = "놀이열쇠 키링".

### 2.3 차점

| 후보 | 강점 | 감수할 것 |
| --- | --- | --- |
| 까르르 | 웃음소리 그 자체 — 5~9세 정서 최강 | 키즈카페류 상호로 흔할 가능성, 10대에겐 유아틱 |
| 사랑이네 | 기존 자산 계승, "○○네"의 온기 | '사랑' 일반명사 문제 잔존, 동네 가게 감성 |

### 2.4 원안 평가 기록 (2026-08-12 논의)

- **"아빠 이리와"** — *아이가 부모를 소환한다*는 통찰이 넷 중 최고. 다만 '아빠'는 지운 프레임이고 '이리와'는 반려동물 호출 연상 → 소환이라는 씨앗만 계승.
- **"역할놀이에서 해방"** — 이름감이 아니라 부모향 광고 카피감. "놀아주는 법을 몰라도 됩니다"류 마케팅 문장으로 활용.
- **"AI 플레이그라운드"** — 기준 1·3 탈락 (5살이 발음 못 함, AI가 주인공이 됨). 놀이터의 온기만 유효.
- **"AI놀이박스"** — '박스' 패턴의 본질은 "이름=실물"인데 우리 실물은 키링. 같은 패턴의 정직한 적용이 '열쇠'.

### 2.5 확정 전 확인

- **KIPRIS 상표 검색** — 9류(앱)·41류(교육·오락)·28류(완구). 2026-08 웹 검색 기준 "놀이열쇠" 정확 일치 앱·서비스는 없음. 이 시장 1위 앱은 '놀이의발견'(웅진, 키즈카페 예약 — 영역 다름).
- 스토어 이름 중복, 도메인 (한글 그대로 또는 `nolkey.kr`류 축약).

### 2.6 확정 시 반영 지점

`index.html`의 `<title>`·헤더 문구, PWA manifest name, 발표 자료. NFC 스티커는 URL이 그대로면 재굽기 불필요 — 도메인을 바꾸면 **스티커 잠금 전에** 재굽기.

## 3. 착수 순서 (발표 뒤)

1. 이름 확정 (KIPRIS 확인) → 반영
2. 익명 가족 코드 + 실시간 채널 (Supabase)
3. 정원 액자 모드(대기 무대) → 무궁화꽃 무대 분리 순으로 게임 확장
4. PWA (설치·푸시 1탭 단)
5. 폰 실기기 판정 튜닝은 이와 무관하게 계속 (CLAUDE.md '남은 것')
