## 2. 구현된 것 (전부 배포됨)

### 진입 의식
- **NFC 키링 톡 → 사이트 → 가족사진 대문**: 카카오톡 프로필처럼 가족이 사진 등록·교체. 이 폰에만 저장(최대 1000px 축소, 초과 시 640px 재시도). 키링 의식은 사진 위 🔑 배지로 유지.
- 게이트 → 참여자 선택 → 놀이 선택. **가온이는 놀이가 정해지기 전엔 등장하지 않는다.**

### 놀이 5종
| 놀이 | 가온이 역할 | 핵심 구현 |
| --- | --- | --- |
| 🌺 무궁화꽃 | 사회자+심판 | 카메라 프레임 차분 판정(자동노출 보정 + 구호 끝 350ms 유예 + 연속 2샘플 확증) · 아이 관대 0.12 / 어른 엄격 0.035 · 아이 걸려도 50%는 "바람인 걸로" · 카메라 거부 시 수동 모드 · `?debug` 실측 오버레이 |
| 🕺 몸으로 말해요 | 사회자 | 이모지 문제 출제, 45초, 정답 공개만 |
| 🔤 끝말잇기 | 놀이 친구 | **어른 2명 이상이면 구경 모드로 물러남**(사람이 먼저) · 단어장 + 아이가 잇기 쉬운 글자 우선 · 12% 의도 패배 · 어른 단어는 음성 우선 입력 |
| 🩺 병원놀이 | 가이드 | 이어폰 대본 — 아이 앞에 안 나타나고 어른에게 "할 말"만 |
| 🚓 경찰놀이 | 가이드 | 〃 |

### 성장·기록
- 놀이 끝 → **아이가 꾹 눌러 물 주기**(하루 1방울, 처음 하는 놀이 +2) → 10방울 개화(아이가 이름 지음) → 정원.
- **꽃 = 기록 캡슐**: 꽃/화분을 누르면 그 시절 기록(사진·한마디·도장)이 펼쳐진다.

### 입력 규약 (2026-08-10)
- **음성 우선**: 부모가 치던 텍스트 3곳(끝말잇기 어른 단어 · 꽃 이름 · 기록 한마디) 전부 "🎤 말로 넣기"가 주, 타이핑은 교정·폴백. 실패 시 1.8초 피드백 후 복귀 — 흐름을 막지 않는다.
- 아이 단어는 입력 자체가 없다(가온이가 귀로만 듣는 구조).

### 검증된 것 (2026-08-10 리허설)
- 전체 시연 동선 통과: 게이트(사진 등록·유지) → 참여자 → 무궁화꽃 → 승리 → 물 주기 → 기록 → 정원 캡슐.
- 실패 경로 확인: 카메라 거부→수동 모드, STT 실패→타이핑 폴백, 같은 날 재놀이→"벌써 줬어요" 분기, 끝말잇기 12% 패배 화면.
- 모바일 3규격(390×844 · 320×568 · 844×390) 레이아웃 통과. 세팅 화면만 320×568에서 ~100px 스크롤(수용).

## 3. 남은 일

### 🔴 발표 전 필수
1. **폰 실기기 실측** — `https://love-web-cyan.vercel.app/?debug` 로 무궁화꽃 판정 수치(지금/최대/기준) 확인 → [src/lib/motion.ts](../src/lib/motion.ts) 임계값 확정. *멈췄는데 최대값이 기준을 넘으면 임계값 ↑, 움직여도 못 미치면 ↓. 결과 숫자만 전달하면 확정 반영.*
2. **실폰 최종 리허설** — 프로덕션 URL로 키링 태그 → 무궁화꽃 → 물 주기 한 바퀴. 이때 끝말잇기 "🎤 말로 넣기"(STT 품질)와 TTS 목소리도 같이 확인.

### 🟡 발표 전 선택 (여유 있으면)
- `?debug` 오버레이에 **라운드별 수치 자동 기록 + "결과 복사" 버튼** — 실측을 붙여넣기 한 번으로 끝내는 편의 기능 (제안됨, 지시 대기).

### 🟢 발표 후 — 1.5차 ([03-phase15-plan](03-phase15-plan.md))
- **멀티스크린 무대**: 가족 코드 6자리 1회 페어링 → 거실 큰 화면이 대기 무대로, 태그 순간 깨어남 (폰=비밀·입력·카메라, 큰 화면=가온이의 무대).
- **PWA**: 홈 화면 설치·오프라인 셸.
- **제품 이름 확정**: '놀이열쇠' vs '가온이' 통합.
- NFC 태그 잠금.

### ⚪ 그 뒤 (스펙에 적어둔 후속)
- 역할놀이 AI 대본 생성·서버 저장·보호자 동의(서버가 처음 생기는 지점 — 개인정보 설계 필요).
- 동화 같이 읽기 · 가족 영화 보고 이야기하기.
- 2차(10~18세, 큰 화면 공유 — [02-phase2-plan](02-phase2-plan.md)).
