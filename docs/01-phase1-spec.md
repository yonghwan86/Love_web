## 1. 한 줄 정의

아이가 **자기 키링을 어른 폰에 대면** 놀이가 열리고, AI **가온이**가 그 놀이에 맞는 역할(사회자·심판·놀이 친구·가이드)로 등장해 **놀이를 굴린다. 놀이에 끼지는 않는다.**

## 2. 플랫폼의 목적 세 가지

| 목적 | 이 제품이 하는 일 |
| --- | --- |
| AI 문화 확산 | 아이가 처음 만나는 AI를 "사람 대신 놀아주는 존재"가 아니라 "사람끼리 놀게 해주는 존재"로 각인시킨다 |
| 소통 부재 해소 | 마음은 있으나 첫 마디·레퍼토리가 없는 어른에게 대본과 진행을 준다 |
| 가족의 온기 | 10분씩 쌓인 놀이를 자라는 식물과 기록 캡슐로 남긴다 |

## 3. 문제 정의 (타깃 사용자 인터뷰에서 확정)

> "너무 사랑하지만 놀아주는 방법을 모르거나… 짧은 시간으로도 깊이 있는 유대감을 쌓을 수 있게 플랫폼을 이용하는 거지"

- **쓰지 않을 프레임**: 학대, 방임, 결손 가정, "소통 못 하는 아빠", "사랑이 부족한 부모"
- **쓸 프레임**: 사랑은 충분하다, 부족한 것은 **레퍼토리와 시간**이다

## 4. 참여자 — "아빠 앱"이 아니다

초기 설계가 아빠 중심으로 그려져 있었으나 이는 오류다. **일상적으로 더 많이 쓸 사람은 엄마**일 가능성이 높다 — "역할놀이 해주는 거 힘들어해"라고 말한 것도, 교육에 지갑을 여는 쪽도 엄마였다.

| 참여자 | 위치 | 설계에 미치는 영향 |
| --- | --- | --- |
| 👩 엄마 | **주 사용자.** 설치·결제·일상 사용 | 역할놀이 대본과 기록 품질이 핵심. "귀찮고 답답하면" 즉시 이탈 |
| 🧑‍🦱 아빠 | **서사 사용자.** 감정적 임팩트 최대 | 첫 마디를 못 떼는 쪽이라 가이드 역할 가치가 가장 크다 |
| 👵👴 조부모 | **숨은 사용자.** 낮 시간 돌봄 | 큰 글씨·적은 조작 — 탭 2번 제약이 이미 만족 |
| 어른 2명 이상 | 주말·저녁 | **사람이 3명이면 가온이는 놀이 친구 자리를 비운다** |

- 세션 시작 시 **"오늘 누가 같이 놀아요?"** 화면에서 엄마/아빠/할머니/할아버지를 고른다 (복수 선택 가능)
- 기록에는 "누구와 놀았는지"가 남는다 → 정원의 꽃마다 함께한 사람이 담긴다

## 5. 캐릭터 "가온이" — 하나의 캐릭터, 네 개의 역할

아이에게 **보이고 말도 건다.** 단, **놀이가 정해진 뒤에 그 놀이의 역할을 입고 등장**한다. 역할 없는 상태로 먼저 나와 인사하지 않는다.

### 역할 4종 (아이가 인식하는 기준)

| 역할 | 소품 | 하는 일 | 나오는 놀이 |
| --- | --- | --- | --- |
| **사회자** | 🎤 | 놀이를 열고 규칙을 말하고 순서·시작 신호를 준다 | 무궁화꽃, 몸으로 말해요, 보물찾기 |
| **심판** | 🔔 | 판정만 한다. 진행은 사람이 하고 결과만 말한다 | 무궁화꽃 움직임 판정, 보드게임 규칙 |
| **놀이 친구** | 🙋 | **사람이 둘뿐일 때만** 돌아가며 하는 놀이의 한 자리를 채운다 | 끝말잇기, 스무고개, 초성 퀴즈 |
| **가이드** | 🎧 | 어른 이어폰에만. 아이 앞에 나타나지 않는다 | 모든 역할놀이 (병원·로봇·경찰·카페·탐험) |

역할마다 **색과 소품이 바뀐다.** 글을 못 읽는 아이가 마이크를 보고 "오늘은 진행자구나"를 알 수 있어야 한다.

### 어느 역할에서든 지키는 것
- 어른 없이는 놀이가 시작되지 않는다 — 가온이와 아이 단둘이 노는 모드는 만들지 않는다
- **사람이 있으면 사람이 먼저다** — 어른이 2명 이상이면 놀이 친구 자리를 비우고 사회자·심판으로 물러난다
- 판정은 아이 쪽에 관대하게 기운다 (어른 임계값은 낮게, 아이는 높게)
- **역할이 정해진 뒤에만 등장한다**

### 어느 역할에서도 하지 않는 것
- **가족 구성원 중 누구와도 팀을 이루지 않는다.** 놀이 친구일 때도 셋이 각자다 — 2:1 구도가 생기지 않는다. **편이 갈리는 놀이에는 참가하지 않는다**
- **놀이 안의 사람 역할을 뺏지 않는다.** 술래·의사·환자는 언제나 가족이 맡는다
- **성별로 놀이를 추천하지 않는다.** 아이 성별을 입력받지도, 저장하지도 않는다
- 아이의 말·행동을 평가하지 않는다 (점수·등급·발달 진단 없음)
- 어른을 대신해 사랑을 표현하지 않는다 — 대본은 주되 말은 어른이 한다

> **설계 근거**: "AI랑 아이만 있으면 아빠가 필요 없어지잖아"라는 우려를 구조로 막는다. 가온이는 놀이를 굴릴 뿐 놀이에 끼지 않으므로, 아이가 얻는 성취는 언제나 "엄마·아빠랑 같이 해냈다"가 된다.

## 6. 놀이 목록 — 성별로 나누지 않는다

"병원놀이는 여자아이가, 로봇·경찰놀이는 남자아이가 많이 한다"는 관찰은 사실이지만, **그걸 제품이 학습하면 아이의 선택지를 좁히는 장치가 된다.** 성별을 입력받지 않고, 저장하지 않고, 추천에 쓰지 않는다. **고르는 사람은 언제나 아이다.**

| 놀이 | 분류 | 가온이 역할 | 사람이 맡는 역할 / 진행 |
| --- | --- | --- | --- |
| 🌺 무궁화꽃이 피었습니다 | 몸놀이 | 사회자+심판 | **술래는 사람.** 어른 술래, 아이 도전자(교대). 구호·판정만 가온이 |
| 🕺 몸으로 말해요 | 몸놀이 | 사회자 | 한 명이 표현, 한 명이 맞힘. 문제와 정답 여부만 가온이 |
| 🔤 끝말잇기 | 말놀이 | 놀이 친구 | 셋이 돌아가며. **어른이 둘이면 사람 셋이서** 하고 가온이는 사회자로 |
| 🩺 병원놀이 | 역할놀이 | 가이드 | 아이가 의사, 어른이 환자 |
| 🤖 로봇놀이 | 역할놀이 | 가이드 | 아이가 조종사, 어른이 로봇. "명령을 그대로 따르는 어른"이 핵심 재미 |
| 🚓 경찰놀이 | 역할놀이 | 가이드 | 아이가 경찰, 어른이 길 잃은 시민/도둑 |
| 🍳 소꿉·카페놀이 | 역할놀이 | 가이드 | 아이가 사장, 어른이 손님 |
| 🦖 공룡·우주 탐험 | 역할놀이 | 가이드 | 아이가 탐험대장, 어른이 대원. 거실이 지형 |

**모든 역할놀이의 공통 원리**: 아이를 돌보거나 지시하는 쪽에, 어른을 도움받는 쪽에 놓는다. 의사–환자, 조종사–로봇, 경찰–시민, 사장–손님이 전부 같은 구조다. **평소와 권력 관계가 뒤집히는 것**이 아이가 이 놀이를 사랑하는 이유다.

1차 개발 범위는 몸놀이 2종 + 말놀이 1종 + **역할놀이 3종(병원·로봇·경찰)** 추천 — 대본 품질이 개수보다 중요하다.

## 7. 시간 정책 — 10분은 시작 약속이지 종료 강제가 아니다

**놀이 도중 타이머로 끊는 것은 최악의 설계다.** 신나게 놀던 아이를 화면이 자르면 그날 이후 이 앱은 "재미를 뺏는 물건"이 된다.

| 시점 | 동작 |
| --- | --- |
| 00:00 | "10분이면 되니까"로 어른을 앉힌다. **10분은 진입 장벽을 낮추는 숫자**이지 제한 시간이 아니다 |
| 첫 판 종료 | **물방울 확정.** 이후 폰이 꺼지든 중단되든 받은 물은 사라지지 않는다 |
| 10:00 | **진행 중인 판은 절대 자르지 않는다.** 판이 끝난 뒤 "한 판 더 할까?"를 묻는다. 이때 "물은 이미 받았어요"를 먼저 알린다 |
| 30:00 | "오늘은 여기까지 할까?" 부드러운 마무리 제안. **강제 종료 없음** — 어른의 체력이 자연 종료 신호다 |

- **물방울은 하루 1개.** 여러 번 놀아도 물은 하나다. 세션 반복마다 물이 늘면 "물 받으려고 노는" 구조가 되고, 피하려던 외적 보상 문제가 그대로 돌아온다. 더 노는 것의 보상은 **더 논 그 자체**여야 한다
- **중단·복귀**: 세션은 30분간 살아 있다. 전화가 오거나 폰이 잠겨도 키링을 다시 대면 이어서 진행된다. 30분이 지나면 세션은 닫히지만 **확정된 물방울과 기록은 남는다**

## 8. 사용자 플로우 (14화면)

1. 아이가 키링을 어른 폰 뒤에 댄다 → 브라우저 자동 열림
2. **"오늘 누가 같이 놀아요?"** — 엄마/아빠/할머니/할아버지, 복수 선택. "지난번이랑 같아요" 단축 버튼
3. **놀이 고르기 — 여기까지 가온이는 나오지 않는다** (카테고리: 몸으로 노는 놀이 / 되어 보는 놀이. 안 해본 놀이에 💧2 표시)
4. 가온이가 그 놀이의 역할을 입고 등장 (소품 + 색으로 역할 표시)
5. **사람끼리 역할 나누기** (술래는 누구?) — 가온이 칸은 회색 비활성으로 "못 해요"를 눈으로 보여준다
6. 세팅 안내 10초 — 폰을 세워 둘 다 보이게
7. 놀이 진행 (사회자: 구호와 신호)
8. 판정 (심판: 아이에게 관대하게)
9. 승리 — 사람과 사람 사이에서 일어난다. 바로 역할 교대 제안
10. **10분 시점, 판 종료 후** — "한 판 더 할까?" (물방울은 이미 확정임을 안내)
11. **물 주기 — 아이가 직접** (세션 완주 1방울, 새 놀이 2방울, 하루 최대 1회)
12. **개화** (10방울째) — 아이가 꽃 이름을 짓는다
13. **우리 정원** — 꽃을 누르면 그 열 번의 기록이 펼쳐진다
14. 오늘 기록 1장 + 아이가 어른에게 주는 도장

**어른 조작은 탭 2번뿐이다. 물 주기와 이름 짓기는 아이 몫이다.**

## 9. 무궁화꽃 판정 로직 (1차 킬러 콘텐츠)

- AI 추론 비용 0원 — 브라우저 안에서 canvas 픽셀 차분만 계산
- 영상이 기기 밖으로 나가지 않음 → 프라이버시 저항 최소
- "어린애들은 몸으로 놀아주지"라는 타깃 피드백과 정확히 일치

1. 가온이가 "무궁화꽃이 피었습니다" 발화 (TTS 또는 녹음)
2. 발화 종료 시점에 기준 프레임 캡처
3. 이후 0.5초간 프레임 차분 누적, 사람 영역별 변화량 산출
4. 임계값 초과 → "움직였다" 판정
5. **임계값은 역할별로 다르게**: 어른은 민감하게, 아이는 둔감하게
6. 술래는 사람이므로, 가온이는 술래의 "돌아본다" 타이밍만 신호로 알린다

## 10. 보상 설계 — 씨앗에서 꽃까지

눈에 안 보이는 유대감을 **자라는 식물**로 보이게 만든다. 즉시 보상이 아니라 **지연 보상**이라 교육적으로 안전하고, 아이는 "오늘 논 것"이 아니라 **"계속 놀아온 것"** 을 보게 된다.

### 성장 5단계

| 단계 | 필요 물방울 |
| --- | --- |
| 🌰 씨앗 | 0 (처음 놀이를 열면 받는다) |
| 🌱 새싹 | 2 |
| 🪴 줄기와 잎 | 5 |
| 🌿 봉오리 | 8 |
| 🌸 꽃 | 10 (정원에 심긴다) |

10방울 ≈ 주 2~3회 기준 **약 한 달에 꽃 한 송이**.

### 물방울 규칙
- **세션 완주 = 1방울**, **처음 해보는 놀이 = 2방울**, **하루 최대 1회**
- 물은 **놀이로만** 생긴다. 돈으로 살 수 없다
- 물은 **아이가 직접 준다.** 세션의 마침표를 어른이 아니라 아이 손으로 찍는다

### 식물은 죽지 않는다 (가장 중요한 제약)

안 놀면 **자라지 않을 뿐**이다. 시들지 않고, 경고도 없고, "며칠째 안 왔어요"도 없다. 화면에는 **"지유를 기다리고 있어요"** 만 뜬다.

> **왜 시들게 하지 않는가.** 식물이 죽는 구조는 결국 연속일수 스트릭과 같다 — 못 논 날 죄책감을 물리는 장치다. 이 제품이 겨냥하는 사람은 **이미 바빠서 못 놀아주는 어른**이라서, 벌을 주면 앱을 지운다.

### 꽃 = 기록 캡슐
- 꽃 한 송이 = **그 열 번의 사진과 아이 말, 함께한 사람**. 꽃을 누르면 그동안이 펼쳐진다
- **아이가 꽃 이름을 직접 짓는다** ("엄마느림보꽃"). 맞춤법은 고치지 않는다
- 꽃은 **정원**에 쌓인다 → 유료 구독의 실제 가치
- **실물 연계(2차 굿즈)**: 꽃이 필 때마다 진짜 씨앗 봉투를 보낸다. 봉투에 아이가 지은 꽃 이름 인쇄. 원가 500원

### 아이 → 어른 도장

아이가 어른에게 "오늘 잘 뛰었음" 도장을 준다. 아이를 받는 쪽이 아니라 **주는 쪽**에 놓아, 아이 행동에 외적 대가가 붙지 않게 한다.

**1차에 넣지 않는 것**: 개인 점수, 랭킹, 연속일수(스트릭), 시들기·재촉 알림, 현실 물건 교환, 다른 가족과의 비교.

## 11. 영상 로드맵 — 같이 보는 것까지 (1차 후속~2차)

**보는 것 자체는 목적이 아니다.** 이 제품이 "아이를 앉혀 놓는 도구"가 되는 순간 정확히 반대 방향으로 간다. 영상은 **이야깃거리를 만드는 재료**로만 쓴다.

| 단계 | 내용 | 기술·제약 |
| --- | --- | --- |
| 1차 후속 | **동화 같이 읽기** — 가온이가 읽어주다 멈추고 어른에게 질문 한 줄을 건넨다 ("지유라면 어떻게 했을까?") | 저작권 자유 창작 동화부터 |
| 1차 후속 | **가족 영화 보고 이야기하기** — 끝난 뒤 가온이가 대화 질문 3개 | 유튜브는 IFrame API로 임베드 가능. **넷플릭스는 웹 임베드 불가**(DRM·약관) → "넷플릭스에서 보세요" 안내 + 시청 후 대화 세션만 |
| 2차 | **취향·나이 맞춤 추천** — 액션·가족 멜로 등 자녀 취향에 맞춰 부모와 볼 작품 추천 | 추천 기준은 나이와 직접 고른 취향뿐. 성별로 추천하지 않는다 |

> **영상 기능의 최대 위험**: 편하기 때문에 영상만 쓰게 된다. 그래서 **영상 세션만으로는 물방울이 나오지 않는다** — 보고 나서 대화까지 마쳐야 지급한다.

## 12. 피지컬 — 집에 있는 키링 + NFC 스티커

- **살 것**: NTAG213 스티커 25mm (10장 3~5천원)
- **굽는 법**: NFC Tools 앱 → Write → URL/URI → 주소 입력 → 태그에 대기. 완료 후 lock 처리
- **함정**: 금속 키링에 일반 스티커는 **전혀 인식되지 않는다.** 방자(anti-metal) 타입을 쓰거나 인형·플라스틱·가죽 키링에 붙일 것
- **동작**: iOS는 잠금 해제 상태에서 배너 알림 → 탭 → 사파리 (iPhone XS 이상). 안드로이드는 즉시 열림. **앱 설치 불필요**

## 13. 기술 구성

| 영역 | 방식 | 비고 |
| --- | --- | --- |
| 입장 | NFC 태그 URL → 세션 토큰 (30분 유효, 재태그로 복귀) | QR 폴백 유지 |
| 카메라 판정 | `getUserMedia` + canvas 프레임 차분 | 전송·저장 없음, 기기 내 처리 |
| 가온이 음성 | Web Speech TTS (기존 speak 자산 재사용) | 고정 대사는 녹음 파일 우선 |
| 역할놀이 대본 | 서버 AI 엔드포인트 (`app/api/ai` 확장) | 어른 이어폰 출력 전용 |
| 기록 | 프레임 1장 + 아이 발화 1줄 + 함께한 사람 | 기존 가족 기록 인프라 재사용 |

## 14. 프라이버시

- 영상은 서버로 보내지 않는다. 움직임 판정은 전부 브라우저 안에서 끝난다
- 저장되는 것은 세션당 정지 프레임 1장 + 텍스트 1줄 + 참여자(엄마/아빠/조부모 구분만)
- **아이 성별은 수집 항목에 없다**
- 아이 음성 인식 결과는 텍스트만 남기고 오디오는 폐기
- 만 14세 미만 개인정보이므로 보호자 동의 필수, 기존 익명 ID 체계 승계
- 세팅 화면에 "영상은 저장하지도 보내지도 않아요" 상시 노출

## 15. 성공/실패 판정 기준

- **성공**: 세션 완주율, 세션당 웃음 횟수, 4주차 재사용률, **참여 어른의 다양성**(엄마·아빠 모두 등장하는 가정 비율)
- **실패 신호**: 세팅이 30초를 넘김 / 어른 조작이 탭 2번을 넘김 / 3회 사용 후 이탈 / 영상 기능만 쓰는 가정 비율 급증

## 16. 아직 검증 안 된 가설 (가장 큰 위험)

1. **3회 쓰고 그만두지 않는가** — 대본이 아이 반응에 따라 갈라지지 않으면 이 제품은 3주짜리다
2. **거실에 카메라를 세우는 심리적 저항** — 남는 저항이 있다면 소리 전용 모드가 필요할 수 있다
3. **판정 정확도** — 조명·역광·좁은 거실에서 프레임 차분이 오작동하면 게임이 성립하지 않는다
