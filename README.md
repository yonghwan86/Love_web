## 한 줄 정의

아이가 **자기 키링을 어른 폰에 대면** 놀이가 열리고, AI **가온이**('가족의 온기'를 줄인 이름)가 그 놀이에 맞는 역할로 등장해 놀이를 굴린다. 어른은 엄마·아빠·조부모 누구든 된다. 놀이가 끝나면 아이가 **물 한 방울**을 주고, 열 방울이 모이면 씨앗이 **꽃**을 피운다.

## 이 컨셉의 핵심 규칙 두 개

**① 가온이는 가족 안에 편을 만들지 않는다.**
중립(사회자·심판·가이드)이거나, 돌아가며 하는 놀이에서 한 자리를 맡는 놀이 친구이거나 둘 중 하나다. 가족 구성원 한 명과 팀을 이루는 일은 없고, 편이 갈리는 놀이에는 참가하지 않는다.

**② 가온이는 놀이에 끼지 않는다. 놀이를 굴릴 뿐이다.**
술래·의사·환자 같은 **놀이 안의 사람 역할은 언제나 가족이 맡는다.** 무궁화꽃에서 가온이가 술래를 하면 아이가 달려가 등을 치는 신체 접촉이 사라진다 — 놀이의 알맹이를 AI가 가져가는 셈이다.

여기서 나오는 부수 규칙: **놀이가 정해지기 전에는 가온이가 등장하지 않는다.** 역할이 정해져야 어떤 모습으로 나올지 결정되기 때문이다.

**③ 식물은 죽지 않는다.**
안 놀면 자라지 않을 뿐이다. 시들기·경고·재촉은 넣지 않는다. 이 제품이 겨냥하는 사람은 이미 바빠서 못 놀아주는 어른이라서, 벌을 주면 앱을 지운다.

**④ 사람이 있으면 사람이 먼저다.**
가온이의 '놀이 친구' 자리는 사람이 둘뿐일 때만 발동한다. 어른이 2명 이상이면 사회자·심판으로 물러난다.

**⑤ 성별을 입력받지도, 저장하지도, 추천에 쓰지도 않는다.**
병원놀이·로봇놀이·경찰놀이 전부 같은 목록에 있다. 고르는 사람은 언제나 아이다.

## 가온이의 역할 4종

| 역할 | 소품 | 하는 일 | 예시 |
| --- | --- | --- | --- |
| 사회자 | 🎤 | 놀이를 열고 규칙·순서·시작 신호를 준다 | 무궁화꽃, 몸으로 말해요 |
| 심판 | 🔔 | 판정만. 진행은 사람이 한다 | 무궁화꽃 움직임 판정, 보드게임 |
| 놀이 친구 | 🙋 | 사람이 둘뿐일 때만 한 자리. 편이 갈리는 놀이엔 안 들어간다 | 끝말잇기, 스무고개 |
| 가이드 | 🎧 | 어른 이어폰에만. 아이 앞에 안 나타난다 | 병원·로봇·경찰·카페놀이 |

## 시간 정책

10분은 **시작 약속이지 종료 강제가 아니다.** 진행 중인 판은 절대 자르지 않고, 판이 끝난 뒤 "한 판 더 할까?"를 묻는다. 첫 판을 마치면 물방울이 확정되고, 이후 중단돼도 사라지지 않는다. 물은 **하루 한 방울** — 더 노는 것의 보상은 더 논 그 자체다.

## 성장 시스템

세션 완주 = 물 1방울, 처음 하는 놀이 = 2방울.
🌰 씨앗(0) → 🌱 새싹(2) → 🪴 줄기와 잎(5) → 🌿 봉오리(8) → 🌸 꽃(10)

꽃 한 송이 = 그 열 번의 사진과 아이 말이 담긴 **기록 캡슐**. 아이가 이름을 짓고, 정원에 쌓인다.
꽃이 필 때마다 **진짜 씨앗 봉투**를 보내 화면 속 꽃을 베란다 화분으로 넘긴다(2차 굿즈).

## 설계 이력

타깃 사용자(초등 저학년 자녀를 둔 어머니) 인터뷰로 초기 컨셉의 기둥 두 개를 폐기했다.

| 폐기한 것 | 사유 |
| --- | --- |
| 두 폰을 겹쳐 화면을 끈다 | 저학년은 애초에 폰이 없어 "둘 다 내려놓기"가 성립하지 않음 → 폰을 **카메라로 돌려세우는** 방식으로 교체 |
| AI가 음성으로 보드게임을 진행한다 | "직접 만지고 경험하는 걸 엄마들은 더 중요시해" → 모든 놀이를 **실물·몸**으로 교체 |
| AI가 무궁화꽃의 술래를 한다 | 아이가 달려가 등을 치는 신체 접촉이 사라짐 → **술래는 사람에게 돌려주고** 가온이는 사회자·심판으로 |

살아남아 코어가 된 것: **"카메라로 비추면서 팁 주는 건 괜찮고"** — 승인된 유일한 개입 방식.

## 절대 쓰지 않는 표현

학대, 방임, 결손 가정, "소통 못 하는 아빠", "사랑이 부족한 부모".
사용자를 결핍으로 규정하면 아무도 쓰지 않는다. 문제는 마음이 아니라 **레퍼토리와 시간**이다.

## 실행 방법

```powershell
npm.cmd install
npm.cmd run dev        # http://localhost:5173
npm.cmd run build      # typecheck + 프로덕션 빌드 (dist/)
```

- 무궁화꽃 판정은 카메라 권한이 필요하다. 권한이 거부되면 자동으로 수동 판정 모드(술래의 눈)로 진행된다.
- 폰 실기기 테스트는 HTTPS가 필요하다(LAN http에서는 getUserMedia 차단). 배포 후 그 URL을 NFC 스티커에 굽는다.
